# Diccionario de español para el corrector ortográfico

`es.aff` y `es.dic`: diccionario genérico de español (todas las variantes) del proyecto RLA-ES
(https://github.com/sbosio/rla-es), de Santiago Bosio, tal como lo distribuyen LibreOffice y Debian
(paquete `hunspell-es` 1:24.2.1). Licencia: GPL-3+ o LGPL-3+ o MPL-1.1+ (a elección).

Xournal JackMath lo lee con Hunspell (ver `src/core/control/tools/SpellChecker.cpp`). Las palabras que el usuario
agrega quedan en `diccionario-personal.txt` de la carpeta de configuración.
